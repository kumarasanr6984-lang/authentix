# Authentix — AI College Admission Verification Platform
> **Smart India Hackathon 2026** · **Problem Statement ID: SIH26261**  
> *Smarter Admissions. Trusted Verification.*

Authentix is a production-grade, full-stack educational technology platform architected to automate preliminary admission scrutiny, multi-document optical character recognition (OCR), fuzzy cross-document verification, and regulatory compliance checks for engineering institutions receiving 1,000–1,500+ applications per cycle.

## 🚀 Key Workflow

1. **Direct College Code Entry**:
   - The application loads directly on the **Smart College Selection** interface.
   - Enter `2026` for Asteria Institute of Technology or `2025` for Bluecrest College of Engineering to proceed straight to application or view institutional profile.

2. **Multi-Section Student Application Form**:
   - Bio-data with automatic age calculation from DOB.
   - Tenth standard SSLC marks, register number, and automatic percentage calculation.
   - Twelfth standard HSC marks with automatic Engineering Cutoff calculation (`Maths / 2 + Physics / 4 + Chemistry / 4`, Maximum 200).
   - Certificate identifiers with masked Aadhaar (`XXXX-XXXX-1234`).
   - 3 department preferences with duplicate prevention.
   - Community category, Tamil Nadu 7.5% Government School Preferential Quota, and disability declarations.

3. **Autonomous Document Verification**:
   - Upload cards for 10 document types.
   - Animated 7-stage verification engine with OCR text matching, Levenshtein distance cross-document analysis, QR verification, and AICTE compliance scrutiny.

4. **Tracking & Smart Correction Assistant**:
   - Real-time application timeline.
   - Dynamic correction assistant for resolving officer requests with audit trails.

5. **Administrative Console**:
   - Scoped strictly to the logged-in college.
   - Executive Command Center, live department seat availability, decision scrutiny, and downloadable PDF/CSV audit reports.
